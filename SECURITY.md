# Security Policy & Vulnerability Disclosure

RitualDev Lab takes the security of **dbshield-python** (`dbshield-python` PyPI SDK) seriously.

## Supported Versions

| Version | Supported | Minimum Runtime | Response Target |
| :--- | :---: | :---: | :---: |
| **0.2.x** | Active | Python >= 3.9 | Critical & High: < 24 Hours |
| < 0.2.0 | End-of-Life | Python >= 3.8 | Upgrade to latest 0.2.x |

## Reporting a Vulnerability

Please **do not** open public GitHub issues for undisclosed security vulnerabilities.

- **GitHub Private Security Advisory (Preferred)**: [Report a Security Advisory](https://github.com/RitualDev-Lab/dbshield-python/security/advisories/new)
- **Email**: `security@ritualdev.in` with subject `[SECURITY VULNERABILITY] dbshield-python`

## Compliance & Control Alignment

- **Status**: SOC 2 Type II & ISO 27001 Control-Mapped Architecture (**Self-Attested Readiness; Formal Independent Audit Planned**).
- **Trust & Control Mapping Portal**: [https://ritualdev.in/trust](https://ritualdev.in/trust)
